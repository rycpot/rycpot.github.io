# Word lists

The word search's word lists, one per language (`<language>.txt`): one word per line, most common
first. Made by `tools/word-packs.py` from [wordfreq](https://github.com/rspeer/wordfreq) by Robyn Speer
(its data is under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)), keeping only
dictionary words. These lists are shared under the same license. The release publishes this folder
at https://rycpot.github.io/extra-guac/words/.
